1. Alcance

Se ejecutaron 15 pruebas técnicas (PT-01 a PT-15) sobre la infraestructura real (MySQL 8.4 y Hyperledger Fabric 2.5 en Docker, Windows 11, Node.js 24), además de 60 pruebas automatizadas (49 unitarias de la aplicación, 3 de integración real y 8 del chaincode) y los 8 casos de fallo del informe H3-05. Se registraron y verificaron 18 registros. Los datos son de validación (ficticios, generados por el seed); el conjunto real autorizado de la institución se incorporará en el Hito 6.

Cada resultado obtenido proviene de una ejecución real cuya salida de terminal se incluye tal cual, extraída de la carpeta evidencias/. No se incluyen capturas simuladas.

5. Fallos encontrados durante las pruebas

Según el procedimiento acordado, se documentan las pruebas que fallaron, su causa y la corrección. Todas se corrigieron y volvieron a ejecutarse.

PruebaErrorCausa probableCorrección
Conexión Fabric (PT-07, primera ejecución)IDENTITY_INVALIDFABRIC_CERT_PATH apuntaba a signcerts/cert.pem, pero cryptogen nombra el archivo User1@…-cert.pem.La ruta apunta al directorio signcerts/; el cliente lee el archivo que contiene. PT-07 aprobada tras la corrección.
Casos de fallo 7, 8 y 1Clasificados como UNKNOWN y PEER_UNAVAILABLELos patrones de error no contemplaban los mensajes reales de Fabric 2.5.Se añadieron patrones y los códigos ORDERER_UNAVAILABLE y ENDORSEMENT_FAILED, con pruebas unitarias basadas en los mensajes reales; los casos se repitieron.
Suite Jest (primera ejecución)SyntaxError: Cannot use import statement outside a module (@noble/curves)Una dependencia de fabric-gateway se publica solo como ESM.jest.config.js transforma @noble/* con ts-jest.
PT-11 (primera ejecución)Authentication failed … credentials for rootsetupEnv.ts fijaba DATABASE_URL y HMAC_SECRET de prueba antes de cargar .env.En modo integración se carga .env primero. 3/3 aprobadas.
npm run check con la base eliminadaEl error de Prisma se mostraba como EVIDENCE_NOT_FOUNDSe aplicaba la clasificación de Fabric a todos los errores y el patrón «does not exist» era demasiado amplio.Solo se clasifican FabricError y se muestra la causa de Prisma; patrón restringido.
Verificación de privacidad On-chain (primera ejecución)Resultado «0 coincidencias» NO válidodocker cp falló por la ruta /tmp de Windows y el buscador no leyó ningún término.Se repitió pasando los términos por stdin; se registra que se leyeron los 82 términos y se añadió un control positivo.

6. Conclusión

Las 15 pruebas técnicas se aprobaron. La cadena completa MySQL → canonicalización → HMAC-SHA-256 → Fabric Gateway → endoso de ambas organizaciones → ledger → TX_ID → MySQL funciona, y la verificación posterior distingue los registros íntegros de los alterados. El criterio del hito, «Blockchain y almacenamiento Off-chain operan de forma integrada», se considera cumplido.
