# Taller de HTML desde cero

Material para estudiantes de secundaria del taller de Vinculación con el Medio (Ingeniería de Sistemas).

Sitio construido con [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) y publicado con GitHub Pages.

Para verlo en tu computadora: `pip install mkdocs-material` y luego `mkdocs serve`.
