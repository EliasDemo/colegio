# 3. Listas

=== "Con viñetas"

    ```html
    <h3>Mis comidas favoritas</h3>
    <ul>
      <li>Ceviche</li>
      <li>Pizza</li>
      <li>Lomo saltado</li>
    </ul>
    ```

=== "Numerada"

    ```html
    <h3>Mi rutina</h3>
    <ol>
      <li>Despertar</li>
      <li>Desayunar</li>
      <li>Ir al colegio</li>
    </ol>
    ```

| Etiqueta | Para qué sirve |
|---|---|
| `<ul>` | Lista con viñetas |
| `<ol>` | Lista numerada |
| `<li>` | Cada elemento de la lista |

!!! example "Reto"
    Haz una lista con tus 3 canciones, juegos o series favoritas.
