# 2. Títulos y texto

Los títulos van de `<h1>` (el más grande) a `<h6>` (el más pequeño).

```html
<h1>Mi página</h1>
<h2>Sobre mí</h2>
<h3>Mis gustos</h3>
<p>Hola, me llamo Ana y estudio en el colegio San Martín.</p>
<p>Me gusta el <strong>fútbol</strong> y la <em>música</em>.</p>
<hr>
```

| Etiqueta | Para qué sirve |
|---|---|
| `<h1>` … `<h6>` | Títulos, de mayor a menor |
| `<p>` | Párrafo |
| `<strong>` | **Negrita** |
| `<em>` | *Cursiva* |
| `<br>` | Salto de línea (no se cierra) |
| `<hr>` | Línea horizontal (no se cierra) |

!!! example "Reto"
    Escribe tu nombre en un `<h1>` y dos párrafos sobre ti. Pon una palabra en negrita.
