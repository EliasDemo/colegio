# Taller de HTML desde cero :material-language-html5:

¡Bienvenido! Hoy vas a crear **tu primera página web** y una **tarjeta de presentación profesional**.

!!! tip "¿Cómo usar esta página?"
    Cada bloque de código tiene un botón :material-content-copy: arriba a la derecha.
    Haz clic para **copiarlo** y pégalo en tu editor.

## ¿Qué es una página web?

Una página web es como una casa:

| Tecnología | En una casa sería… | Para qué sirve |
|---|---|---|
| **HTML** | Los ladrillos | Define **qué** hay en la página |
| **CSS** | La pintura | Define **cómo se ve** |
| **JavaScript** | La electricidad | Define **qué hace** |

Hoy aprenderemos **HTML** y un poco de **CSS**.

## ¿Dónde escribo mi código?

=== "CodePen (recomendado)"

    1. Entra a [codepen.io/pen](https://codepen.io/pen/){target=_blank}
    2. Pega tu código en el cuadro **HTML**.
    3. El resultado aparece abajo al instante.

=== "Bloc de notas / VS Code"

    1. Abre el Bloc de notas o VS Code.
    2. Pega tu código.
    3. Guarda el archivo como `index.html`.
    4. Haz doble clic en el archivo para abrirlo en el navegador.

## Regla de oro

!!! note "Lo que se abre, se cierra"
    Casi todas las etiquetas tienen apertura y cierre:
    ```html
    <p>Hola mundo</p>
    ```
