# Si algo sale mal

| Problema | Solución |
|---|---|
| Todo el texto sale en negrita o grande | Falta cerrar una etiqueta |
| Se desarmó todo el diseño | Falta un `;` o una llave `}` en el CSS |
| El color no cambia | El código debe empezar con `#` y tener 6 caracteres |
| La letra no cambia | El nombre de la fuente va entre comillas y bien escrito |
| La imagen no aparece | El link va entre comillas `"..."` |
| Se abre como texto | El archivo debe terminar en `.html` |
| No veo los cambios | Guarda (++ctrl+s++) y recarga el navegador (++f5++) |
| Tildes o ñ raras | Agrega `<meta charset="UTF-8">` |

!!! tip "Último recurso"
    Vuelve a copiar el código original y cambia **de a una cosa**.
