# Retos

=== "🟢 Nivel 1 – Básico"

    - [ ] Cambia el nombre, la profesión y los datos por los tuyos.
    - [ ] Cambia el color de la franja y de los botones.
    - [ ] Cambia el tamaño del nombre a `30px`.

=== "🟡 Nivel 2 – Intermedio"

    - [ ] Cambia el fondo por una combinación de la tabla de colores.
    - [ ] Cambia el borde de la tarjeta a `dashed` o `double`.
    - [ ] Usa otro tipo de letra de Google Fonts.
    - [ ] Agrega un dato más a la lista.

=== "🔴 Nivel 3 – Experto"

    - [ ] Haz la tarjeta cuadrada: `border-radius: 0px;`
    - [ ] Pon una sombra brillante: `box-shadow: 0 0 25px #00ff99;`
    - [ ] Crea una **segunda tarjeta** copiando todo el `<div class="tarjeta">`.
    - [ ] Haz un **modo oscuro**: tarjeta `#1e1e1e` y letras blancas.
    - [ ] Agrega un `header`, un `nav` y un `footer` alrededor de tu tarjeta.

??? success "Pista para el modo oscuro"
    ```css
    .tarjeta { background-color: #1e1e1e; }
    .nombre, .descripcion, .datos { color: white; }
    ```
